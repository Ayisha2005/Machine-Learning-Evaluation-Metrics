# Machine Learning Evaluation Metrics

## Project Overview
This project demonstrates the evaluation of a Machine Learning classification model using Confusion Matrix, ROC Curve, and AUC Score. The project uses the Breast Cancer dataset available in Scikit-learn and applies Logistic Regression for binary classification.

## Objectives
- Understand classification model evaluation.
- Generate and analyze a Confusion Matrix.
- Plot the ROC (Receiver Operating Characteristic) Curve.
- Calculate the AUC (Area Under Curve) Score.
- Interpret model performance using evaluation metrics.

## Dataset
Breast Cancer Wisconsin Dataset

Source:
Scikit-learn Built-in Dataset

## Algorithm Used
- Logistic Regression

## Technologies Used
- Python
- NumPy
- Matplotlib
- Scikit-learn

## Evaluation Metrics
### Confusion Matrix
Used to evaluate classification performance based on:
- True Positive (TP)
- True Negative (TN)
- False Positive (FP)
- False Negative (FN)

### ROC Curve
The ROC Curve visualizes the performance of the classifier across different classification thresholds.

### AUC Score
The Area Under the Curve (AUC) measures the model’s ability to distinguish between classes.
